5. The opportunity

A growing share of product research, comparison, and recommendation now happens inside AI assistants rather than a traditional results page. When a buyer asks an assistant to "recommend a tool like X" or "compare the best options," it returns a synthesized answer and cites a handful of sources — and most brands cannot see whether they appear, how they are described, or which sources shape the answer.

Answer Engine Optimization (AEO) — also called Generative Engine Optimization (GEO) — is the emerging practice of measuring and improving that presence. It is to AI assistants what SEO was to search engines, and it is early: the tooling category is nascent, and search-visibility budgets are beginning to move toward AI-answer visibility.

Why now. The measurement problem is real, unsolved for most brands, and growing with AI-assistant usage. A platform that already measures AI-answer visibility, citations, and crawler activity is positioned for exactly this shift.

Market characterizations here are qualitative and illustrative; no specific market-size figures are asserted. A buyer should form its own view of category size and timing.

7. Technology & intellectual property

Next.js 16, React 19, TypeScript, deployed on Vercel with GitHub auto-deploy. Type-clean and building cleanly, with a deliberately small dependency footprint. Accurate technical description of the engine:

  • Persistence — a backend-agnostic data layer running in-memory today; the implemented durable backend is Redis/KV (Upstash / Vercel), which activates with a credential. A Postgres backend is a straightforward adapter against the same interface, and is not yet implemented.
  • Authentication — a bespoke account system (scrypt password hashing, sessions). It is built and functional but has no automated test coverage and no independent security review; hardening (rate limiting, lockout, CSRF, session hardening) remains.
  • Scoring — real functions that turn sampled AI answers into the platform's metrics using a documented formula set.
  • Provider integrations — hand-written clients for Perplexity, OpenAI, Anthropic, Gemini, and DataForSEO, written to each provider's documented API but not yet run against live endpoints; verify with live keys during diligence.
  • Telemetry — the genuinely functional first-party AI-crawler and referral capture; per-customer deployment uses a proxy/snippet install.

There is no automated test suite yet — verification to date is type-checking, clean builds, and manual/functional checks. The acquisition transfers full ownership of the original source, the Answr brand and useanswr.com domain, the design system and design canvases, all original content and the metric model, the demo dataset, and the documentation set (schedule in §13/§14).

10. Competitive landscape

The AEO/GEO category is young and active. Dedicated entrants include Profound and Peec AI, with others (e.g. Otterly, Goodie, Scrunch/Athena-class tools) emerging. Two structural threats a buyer should weigh: SEO incumbents (e.g. Semrush, Ahrefs) adding AEO features to large existing user bases, and the AI providers themselves potentially surfacing native analytics.

That several players have raised capital is itself category validation. Answr's position is a build-vs-buy shortcut: a deployed, full-stack platform (visibility, citations, first-party crawler analytics, and an action layer) with the hardest primitive — first-party capture — already working. A buyer should assess where Answr is at parity or behind funded competitors, not only where it may have an edge.
