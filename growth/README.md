# Demand-validation sprint trackers

Open the CSVs in Google Sheets or Excel. See `../GROWTH.md` for the plan and
`../OUTREACH_DRAFTS.md` for ready-to-send copy.

- **outreach-tracker.csv** — one row per prospect. `Status`: Queued / Sent / Followed-up /
  Replied / Dead. `Interest`: Hot / Warm / Cold. `Price signal`: note any "$X/mo" they mention.
- **sprint-metrics.csv** — one row per channel per day. `Waitlist views`, `Signups`, and
  `Positive replies` are the numbers that go on the sale listing.

Live funnel (views / signups / conversion by source) is also visible in the app at
**Settings → Leads → Waitlist funnel**. Tag campaign links with `?utm_source=linkedin`
(etc.) so each channel's conversion is attributed automatically.
