19 environment variables · 5 AI providers · storage · secrets · email · Last updated 14 Sep 2026

How activation works. Every capability turns on the moment its environment variable is set on the deployment (Vercel → Project → Settings → Environment Variables → redeploy). Nothing needs a code change. The Settings → Integrations page in the app shows each provider as Connected / Not connected and has a Test connection button that makes one live call to verify a key.

5 · Setup order (about an hour)

  1. Deploy the repo to your own Vercel account and point useanswr.com at it.
  2. Add storage — create an Upstash Redis DB, set the two KV_REST_API_* (or UPSTASH_*) vars. Persistence is now on.
  3. Set the secrets — DEMO_PASSWORD, ANSWR_INGEST_SECRET, CRON_SECRET.
  4. Add at least one AI key — Gemini with billing enabled is the recommended start. Redeploy.
  5. Verify — Settings → Integrations → Test connection on each provider (green = live).
  6. See real numbers — open /app/scan, enter any brand, click Run live scan.
  7. Add email (Resend) and more providers as desired — each activates on its own.
